# Task Manager

A modern task management web application built with React.

---

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks (All / Active / Completed)
- Data saved using LocalStorage
- Clean and responsive UI

---

## Tech Stack

- React
- Zustand
- Vite
- JavaScript
- CSS
